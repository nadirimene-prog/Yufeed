# YuFeed overview

YuFeed is a compliance intelligence platform focused on two pillars:

1) **EU legal intelligence** — ingest, search, classify, and analyze EU legal texts (EUR-Lex / CELEX).
2) **AML tooling** — transaction monitoring, alerting, investigations, and reporting workflows.

## Key capabilities

### EU legal intelligence
- Ingestion from EUR-Lex / CELEX sources
- Full-text search with OpenSearch
- Classification & summarization (LLM-assisted)
- Obligation extraction and impact assessment

### Transaction monitoring
- Rule engine (logical conditions, thresholds)
- Real-time risk scoring
- Alert generation + triage workflow
- Network / entity relationship analysis

### AI agents
- Agent-assisted investigations and drafting (e.g., SAR support)

## Non-goals
- Replace an institution’s core KYC/KYB stack
- Provide a full case-management product (beyond the included workflow primitives)
